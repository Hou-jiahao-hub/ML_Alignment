# 粒子穿越材料与多重散射

**主要来源：** [@pdg2024passage]、[@actsTracking]

## 文献事实

带电粒子穿越材料时会发生能损和多重库仑散射。对本项目的高能 muon 样本，首版
最直接影响轨迹局部方向的是小角多重散射。常用投影角宽度近似可写为

\[
\theta_0 \simeq
\frac{13.6\,\mathrm{MeV}}{\beta p c}|z|\sqrt{x/X_0}
\left[1+0.038\ln(x/X_0)\right].
\]

这里 `x/X0` 是沿实际入射路径的材料厚度，以辐射长度为单位；`p` 和 `β` 必须与
该节点处的粒子状态一致。该表达式描述的是多重散射分布的高斯核心近似，不是对
稀有大角尾部的完整模型。PDG 还区分平均能损与能损涨落，因此“均值能损可忽略”
不能推出“散射可忽略”。[@pdg2024passage]

ACTS 将材料效应作为传播中的状态更新或过程噪声处理；材料可以被平均到薄表面，
也可以在致密体材料中连续处理。bremsstrahlung 等明显非高斯效应需要比单高斯
过程噪声更复杂的模型。[@actsTracking]

## 对当前项目的含义

- 单一 helix 只能表示平均磁场弯曲，不能表示每条轨迹随机发生的方向改变。
- 随机散射的期望角为零，因此 holdout bias 可以接近零，同时 RMSE 和 pull 宽度
  仍显著偏大；这与当前 nominal 验证的项目观测一致。
- 仅把 measurement covariance 放入分母，会漏掉从拟合区间传播到 holdout 的
  过程噪声。材料感知验证必须报告 predictive covariance，而不只是原始 RMSE。
- `x/X0` 必须包含入射角路径修正。只按几何层赋固定常数，会在斜入射和端盖轨迹
  上产生系统错误。

## 首版边界

- 粒子假设固定为 muon，电荷绝对值为 1。
- kink 先验使用 Highland 高斯核心，尺度由材料与动量确定，不设可训练全局放大
  因子。
- 首版保持 helix 曲率在段间不变；如果残余随路径长度或动量呈系统趋势，再独立
  评估平均能损和能损涨落。
- 大角尾部应通过 pull 尾部和覆盖率诊断，不应立即用 Huber/IRLS 隐藏。

## 待实验验证的项目推断

若多重散射确为当前 χ² 下限的主因，则加入物理 kink prior 后，nominal holdout
的中心 pull 应比单 helix 更接近单位宽度；interpolation 的点预测 RMSE 应下降，
而 one-sided extrapolation 的主要收益可能表现为预测协方差校准，而非均值误差
达到传感器本征分辨率。
