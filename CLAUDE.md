# Development instructions

The authoritative development and agent instructions are in `AGENTS.md`.
Architecture and data contracts are in `docs/architecture.md`.

Before modifying alignment objectives or residual definitions, also read
`docs/ml_alignment_principles.md` and `docs/history/ml_optimization_log.md`.

Work in progress is handed over in `docs/handoff/`. Read the newest file there
first: it carries the current gate status, the pre-registered constants in
force, and what the last session deliberately left undone.
